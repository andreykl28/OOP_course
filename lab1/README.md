# Лабораторная работа №1

Вариант 8. Реализация динамического массива целых чисел на C++.

Поддерживаемые операции:

- создание и удаление массива;
- изменение размера;
- вставка и удаление элементов;
- бинарный поиск элемента;
- слияние двух отсортированных массивов.

## Сборка

Команды выполняются из корня репозитория:

```bash
cmake -S lab1 -B lab1/build
cmake --build lab1/build
```

## Запуск программы

```bash
./lab1/build/lab1_main
```

## Запуск тестов

```bash
ctest --test-dir lab1/build --output-on-failure
```
