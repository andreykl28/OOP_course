# Лабораторная работа №2

Вариант 8. Семейство B: Класс Polynomial (многочлен одной переменной) с ручным управлением памятью, RAII и правилом пяти на C++.

Поддерживаемые операции:

- создание нулевого многочлена и инициализация массивом коэффициентов;
- глубокое копирование и семантика перемещения (Rule of Five, copy-and-swap);
- сложение многочленов (`add`);
- умножение многочленов (`mul`);
- вычисление значения многочлена в точке по схеме Горнера (`evaluate`);
- вычисление производной многочлена (`derivative`);
- вычисление неопределенного интеграла (`integral`).

## Сборка

Команды выполняются из корня репозитория:

```bash
cmake -S lab2 -B lab2/build
cmake --build lab2/build
```

```bash
./lab2/build/lab2_main
```
